# Smart Clipboard

Android 智能剪贴板助手，使用 Kotlin、Jetpack Compose、MVVM 和 Room 开发。

## 当前进度

1. Android Studio 项目骨架：已完成。
2. 手动打开 App 时读取系统剪贴板：已完成，过滤空内容和纯数字/英文字母内容。
3. 保存确认提示：已完成，支持内容预览、展开、保存和忽略。
4. Room 本地数据库、分类和去重：已完成；保存时按网址、邮箱、中国手机号或普通文本分类。
5. 剪贴板列表、管理和搜索：已完成，支持复制、编辑、删除、收藏和手动添加。
6. 批量粘贴导入：已完成，每行一条，跳过空行与重复内容。
7. QQ 输入联想实验版：开关位于设置页，仅在用户同时开启应用开关和 Android 无障碍服务后工作。

## 已确认的 MVP 行为

- 用户打开 App 后主动导入当前剪贴板文本，不在后台监听其他 App 的复制动作。
- 仅由数字、英文字母组成的文本（包括二者混合）不自动提示；保留手动添加入口。
- 输入联想只匹配 QQ（com.tencent.mobileqq）的当前可编辑输入框。输入至少 2 个字、至多 40 个字时，在本地库中查找包含该文本的条目，最多查询 20 条；键盘上方卡片显示约 3 条并可滚动。点击候选会替换当前输入框的全部文本。
- 联想使用 Android 无障碍服务。服务接收窗口变化事件以便离开 QQ 时移除浮窗，只读取 QQ 当前聚焦的非密码输入框，不记录或上传输入文本。不同 QQ 版本及输入法仍可能影响候选显示或插入。
- 可在 App 设置页随时关闭实验开关；也可在系统无障碍设置关闭服务。
- 首页支持即时搜索、可收起的分类与收藏筛选侧边栏、底部导入方式面板和卡片左滑操作。剪贴板导入结果以短暂的顶部提示显示。
- 所有数据保存在本机，不依赖第三方输入法。

## 打开项目

在 Android Studio 中选择 **Open**，打开本目录。需要 JDK 17、Android SDK Platform 35 和 Build-Tools 34。Android Studio 会在本机生成 `local.properties`，该文件和本机 SDK 不会提交到仓库。

运行 `./gradlew assembleDebug` 后，测试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。点击卡片或“复制”会写入系统剪贴板。
